<h1>🐔 Galinho</h1>

<p>
Projeto web interativo desenvolvido utilizando <strong>HTML</strong>, <strong>CSS</strong> e <strong>JavaScript</strong>, 
com foco em uma experiência dinâmica e responsiva para o usuário.
</p>

<h2>📌 Sobre o Projeto</h2>

<p>
O <strong>Galinho</strong> é uma aplicação web que simula um sistema interativo (como jogo, roleta ou apostas), 
oferecendo uma interface visual agradável e funcionalidades dinâmicas no navegador.
</p>

<p>
O projeto foi construído com tecnologias front-end puras, sem dependência de frameworks, 
visando aprendizado, desempenho e simplicidade.
</p>

<h2>🚀 Tecnologias Utilizadas</h2>

<ul>
  <li><strong>HTML5</strong> — Estrutura da aplicação</li>
  <li><strong>CSS3</strong> — Estilização e responsividade</li>
  <li><strong>JavaScript (Vanilla JS)</strong> — Lógica e interatividade</li>
</ul>

<h2>🎯 Funcionalidades</h2>

<ul>
  <li>Interface interativa e intuitiva</li>
  <li>Sistema dinâmico com manipulação de elementos</li>
  <li>Atualização de conteúdo em tempo real</li>
  <li>Animações e efeitos visuais</li>
</ul>
