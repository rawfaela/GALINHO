<h1>🐔 Galinho</h1>

• Projeto web interativo desenvolvido utilizando HTML, CSS e JavaScript, com foco em uma experiência dinâmica e responsiva para o usuário.

📌 Sobre o Projeto

• O Galinho é uma aplicação web que simula um sistema interativo (ex: jogo, roleta, apostas ou similar), oferecendo uma interface visual agradável e funcionalidades dinâmicas no navegador.

• O projeto foi construído com tecnologias front-end puras, sem dependência de frameworks, visando aprendizado, desempenho e simplicidade.

🚀 Tecnologias Utilizadas

• HTML5 — Estrutura da aplicação

• CSS3 — Estilização e responsividade

• avaScript (Vanilla JS) — Lógica e interatividade

🎯 Funcionalidades

• Interface interativa e intuitiva

• Sistema dinâmico com manipulação de elementos

• Atualização de conteúdo em tempo real

• Animações e efeitos visuais
